# Дневник отказов

Мобильное приложение-дневник на **Blazor Hybrid + .NET MAUI**, которое помогает фиксировать ответы **«нет»** и отслеживать прогресс.

> Идея: собрать определенное количество отрицательных ответов на вопрос или просьбу. Теоретически, должно помочь побороть страх отказа.

---

## Возможности:

- Добавление новых отказов
- История записей
- Прогресс до цели
- Светлая/темная темы
- Локальное хранение данных (**SQLite + Dapper**)

## Добавится в ближайшее время:
- Backup / Restore через json
- Система наград
- Статистка
- Категории отказов
